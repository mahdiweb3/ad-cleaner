Ad Cleaner — YouTube  ·  v1.0.0

نصب (Chrome / Edge / Brave):
1. فایل zip را در یک پوشه دائمی استخراج کن (پوشه را بعداً جابه‌جا/پاک نکن).
2. برو به chrome://extensions
3. گوشه بالا راست: Developer mode را روشن کن.
4. Load unpacked -> پوشه‌ای که استخراج کردی را انتخاب کن.
5. یوتیوب را refresh کن.

تست شده: Chrome for Testing 151، پخش ویدیو + بلاک doubleclick/googlesyndication.
